Every module Zuri ships with, and every public name in each one. The
pages here are generated from the library's own doc blocks, so what you
read is what the code says.

This is a reference, not a tutorial. It answers "what does this take and
what does it return". For the narrative version, with worked examples
and the reasoning behind the design, read *The Zuri Programming
Language*, which `cargo run-docs` serves alongside this.
