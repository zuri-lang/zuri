The language, its standard library and its tools in one download

One language, one binary, the entire development lifecycle.

Build for the web without first piecing together a dozen third-party tools.

Zuri comes with a standard library for the full stack, a JIT compiler, and the tools you need to get from the first line of code to a finished app: a formatter, a test runner, a language server, a package manager, a package registry and a bundler.

$ curl -fsSL https://zuri-lang.github.io/zuri/install.sh | sh
> powershell -c "irm https://zuri-lang.github.io/zuri/install.ps1 | iex"
$ git clone https://github.com/zuri-lang/zuri && cd zuri && cargo patch-crates && cargo build --release

Why Zuri?

A language and its libraries, designed together.

In most languages, serving a web page or saving a record to a database starts with research. You pick a package manager, an HTTP framework, a database driver, a validation library and a template engine. Each one comes from a different author, follows its own conventions and has its own documentation.

Learning how the pieces fit together often takes longer than learning the language.

Zuri ships those pieces with the language. The runtime, the server, the database layer and the tools were designed together. They follow the same conventions and they are documented in the same book.

The toolchain

The toolchain comes with the language.

Each of these is a subcommand of the zuri binary. They were built alongside the language and are covered in the same book, so once Zuri is installed, you have all of them.

zuri run

Run anything

Run a script, a package or a whole directory. Run zuri on its own for a REPL, or add -w to run the program again whenever a file changes.

Hello, World! zuri test

Test runner

Each test file runs in its own process, as many at a time as --jobs allows. Filters and timeouts are built in, and the report points to the line that failed.

Testing zuri fmt

Formatter

Formats every Zuri file the same way. Add --dry-run to use it as a check in a commit hook or a CI job.

Formatting zuri lsp

Language server

Completion, navigation, diagnostics, refactoring and test running in any editor that supports LSP.

Editor Support zuri install

Package manager

Resolves version ranges into a lockfile with one version of each package. Use zuri publish to share your own, and --dry-run to preview any command that changes a project.

Commands From Packages

No setup

A complete web service, with no dependencies.

Everything this program imports comes with Zuri, so there is nothing to install or configure before you run it.

signup.zu
import http
import validate
import log

var signups = validate.schema({
  name: validate.required().string().max_length(60),
  email: validate.required().string().email(),
})

var server = http.server(3000)

server.post('/signup', @(request, response) {
  var body = request.json_body() or {}
  var checked = signups.check(body)

  if !checked.valid {
    return response.json({ errors: checked.errors }, 422)
  }

  log.info('signed up ${body.email}')
  response.json({ ok: true }, 201)
})

server.listen()

One binary, plus the library that comes with it. When you do need outside code, package management and vendoring are built into the language, so you still don't need any third-party tools. Not even Zuri's built-in package manager — that exists for convenience.

digests.zu
import isolate
import hash

def digest(text) {
  return hash.sha256(text)
}

# Each call runs on its own OS thread, with its own heap.
var digests = isolate.map(digest, ['alpha', 'beta', 'gamma'])

echo digests.map(@(d) => d[,12])
output
[8ed3f6ad685b, f44e64e75f39, be9d587defa1]

tests/cart.test.zu
import test { * }

def subtotal(items) {
  return items.reduce(@(total, item) => total + item.price * item.quantity, 0)
}

describe('subtotal', @{
  it('is zero for an empty cart', @{
    expect(subtotal([])).to_be(0)
  })

  it('adds up every line', @{
    var cart = [{ price: 4, quantity: 2 }, { price: 10, quantity: 1 }]

    expect(subtotal(cart)).to_be(18)
  })
})

Bundles

Run your program where Zuri isn't installed.

zuri bundle packages your program, the packages it uses, the standard library and the runtime into a single bundle you can give to anyone. It runs the same way on every machine, and there's nothing to install first.

Single executableOne file to download and run. --format exe
macOS appAn application you can open from Finder. --format app
ArchiveA .tar.gz, or a .zip for Windows.
DirectoryUseful for container images. --format dir

Language design

Dynamic, with guard rails.

Zuri's syntax will feel familiar if you've written JavaScript, Python or Ruby. What it adds is a set of checks that dynamic languages usually leave to code review.

Classes are sealed, parameters can declare types that are checked when the function is called, and private methods and module members really are private. These are the mistakes that are easy to miss when you read code, so Zuri catches them for you.

Error messages tell you what went wrong and point to the line where it happened, whether you see them in your editor, at compile time or while the program is running.

account.zu
class Account {
  @new(owner: string) {
    self.owner = owner
    self._balance = 0
  }

  deposit(amount: number) {
    self._balance += amount
    return self._balance
  }
}

var account = Account('ada')

Editor support

Works in the editor you already use.

zuri lsp is a complete language server. It's written in Zuri and uses the compiler's own parser, so the errors in your editor match the ones you'd get when running the code.

  • CompletionMembers, names in scope and module exports. Missing imports are added for you.
  • Diagnostics as you typeThe same messages the runtime gives, with quick fixes where possible.
  • NavigationDefinitions, references, implementations, call and type hierarchies.
  • RefactoringRename across the workspace, extract and inline variables and functions.
  • Hover and signaturesDocumentation formatted the same way as in the reference.
  • Tests and formattingRun a single test from your editor, and format a file or a selection.

Performance

Fast, with no tuning required.

Zuri has a tiered JIT compiler built on Cranelift, the code generator behind wasmtime. Hot code is compiled in the background and specialized for the types it actually uses. You don't need annotations or flags for any of it.

  1. The interpreter

    Your program starts right away as bytecode. Every function starts here, and the runtime keeps track of which ones run most often.

  2. Kebbi

    The fast baseline compiler turns a hot function into machine code that keeps values in registers. It works out what it can about types before compiling.

  3. Bayelsa

    The optimizing compiler represents the function as a graph of typed values. It inlines small functions, moves checks out of loops and speculates based on how the code has behaved so far.

Compiling doesn't block

Both compilers run on background threads. Your program keeps running the code it has until the faster version is ready.

Use every core

Isolates run on OS threads, each with its own heap, so parallel code needs no locks and can't share state by accident.

Native when it matters

When a fast native implementation already exists, call the C or Rust library directly through ffi.

Roadmap

What's done, and what's next.

Done

  • The language, including a zuri module that can parse, compile and inspect Zuri code
  • A tiered Just-In-Time compiler
  • A standard library that covers the full web stack
  • SQLite, PostgreSQL, MySQL and MariaDB through one API
  • An ORM for saving and loading models
  • A test runner and a formatter
  • A language server for any editor that supports LSP
  • Package management built into the runtime
  • Nyssa, a self-hosted package registry in every installation
  • Bundles that run on machines without Zuri
  • C and Rust interop
  • A language guide and a standard library reference

Planned, roughly in order of priority

  • HTTP/3. The http module currently supports HTTP/1.1 and HTTP/2.
  • A public package registry at pub.zurilang.org.
  • A debugger with breakpoints and stepping, for editors that support DAP.
  • A profiler for finding where a program spends its time and memory.
  • OAuth 2 in the standard library, for signing in with other services.
  • Telemetry: exporting traces and metrics over OpenTelemetry.
  • Job scheduling for running tasks at set times or intervals.
  • A GitHub Action for installing Zuri in CI workflows.
