The language, its library and its whole toolchain, in one download

One language, one binary, the entire development lifecycle.

Stop learning an entire constellation of third-party tools just to build on the web.

Zuri ships a standard library that covers the whole stack, a JIT compiler, and every tool from the first line to the shipped app: a formatter, a test runner, a language server, a package manager, a package registry and a bundler.

The ecosystem tax

When you learn Zuri, you already know the stack.

Software creation has become buried beneath endless layers of glue code, external configs and shifting package ecosystems. Zuri brings the focus back to writing software: one cohesive platform, one documentation site, and zero framework fatigue.

When you pick up a modern language, you do not just learn that language. To serve a single web page or persist a record, you must research, evaluate and configure dozens of disconnected third-party libraries. Every piece comes from a different author, follows conflicting conventions, and keeps its own documentation in its own shape.

You spend twenty percent of your time learning core concepts and eighty percent wrestling with arbitrary tool churn.

Zuri removes that tax. The runtime, the server, the data layer and the utility toolchain were designed together and speak the same conceptual dialect.

This is a whole application.

Every import below is in the box: nothing was installed, nothing was resolved, nothing was configured.

signup.zu
import http
import validate
import log

var signups = validate.schema({
  name: validate.required().string().max_length(60),
  email: validate.required().string().email(),
})

var server = http.server(3000)

server.post('/signup', @(request, response) {
  var body = request.json_body() or {}
  var checked = signups.check(body)

  if !checked.valid {
    return response.json({ errors: checked.errors }, 422)
  }

  log.info('signed up ${body.email}')
  response.json({ ok: true }, 201)
})

server.listen()

tests/cart.test.zu
import test { * }

def subtotal(items) {
  return items.reduce(@(total, item) => total + item.price * item.quantity, 0)
}

describe('subtotal', @{
  it('is zero for an empty cart', @{
    expect(subtotal([])).to_be(0)
  })

  it('adds up every line', @{
    var cart = [{ price: 4, quantity: 2 }, { price: 10, quantity: 1 }]

    expect(subtotal(cart)).to_be(18)
  })
})

Language design

Dynamic, and it declines to be vague.

Zuri takes the expressive, familiar syntax of modern dynamic languages and adds deliberate structural controls.

Zuri features true access controls with sealed classes, function parameter type guards, private methods and modules, all enforced by the compiler. The point of each is the same. The things that are hard to see when reading code are the things the language refuses to let you get wrong.

Every error names what went wrong, where, and the line it happened on, whether it surfaces in your editor, at compile time or while the program runs.

account.zu
class Account {
  @new(owner: string) {
    self.owner = owner
    self._balance = 0
  }

  deposit(amount: number) {
    self._balance += amount
    return self._balance
  }
}

var account = Account('ada')

Performance

Fast, without being asked.

A fast Just-In-Time compiler driven underneath by Cranelift, the same engine that drives wasmtime, with cutting edge specialization and optimized to production workloads. The tiering happens on its own, on background threads, with no annotations and no flags.

  1. The interpreter

    Your program starts at once, as bytecode, and every function begins here while the runtime watches what is hot.

  2. Kebbi

    The quick compiler turns a hot function into machine code that keeps values in registers, proving what it can about types before it compiles.

  3. Bayelsa

    The optimizing compiler builds the function as a graph of typed values, builds small functions into their callers, moves checks out of loops and bets on what the code has done so far.

Compiles never block

Both compilers run on background threads. A program carries on in the code it already has until the faster code is ready.

Every core, safely

Isolates run on real OS threads with heaps of their own, so parallel work needs no locks and shares no state by accident.

Native when it matters

Call straight into C and Rust libraries through ffi when a hot path already exists in native code.
