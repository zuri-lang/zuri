Databases

sql.model.query

sql lifts part of this module out to its own top level; each name below is shown with the path that reaches it. Anything still spelled sql.model.query.* needs import sql.model.query.

Reading and writing a model's rows by conditions, as records.

db.model(Post) starts a query on a connection or a transaction. Every method that narrows it returns a new query and leaves the one it was called on as it was, so a query can be kept and built on in more than one direction:

Conditions

where() with a dictionary reads as the CRUD helpers' conditions do: a value matches itself, nil matches null, a list matches any of its values, and an empty list matches nothing. Anything else is a fragment of SQL, with ? for each value:

Every condition must hold. A fragment is bracketed as it is added, so an or inside one stays inside it.

Associations

include() loads associations along with the records, one query per association rather than one per record, and a dotted name reaches further: include('comments.author') loads every post's comments and every comment's author, in three queries however many there are.

Classes

Query

A query over one model's rows.

  • printable — has a @to_string(), so echo and print() show something useful
  • iterable — can be walked with for and iter

Query.definition()

The definition of the model queried.

Returns Definition

Query.where()

Narrows the query to rows meeting conditions.

Parameters

  • filter (dict|string) — Conditions as a dictionary of column to value, or a fragment of SQL.
  • values (list|nil) — For a fragment, the values its ? stand for.

Returns Query

Query.where_not()

Narrows the query to rows not meeting conditions. A row whose column is null is not equal to any value, so it is among the rows a value excludes; nil excludes null itself.

Parameters

  • filter (dict) — Column to value, as where() reads one.

Returns Query

Query.order()

Orders the rows, after any order already given.

Parameters

  • terms (string|list) — Each a column, optionally followed by asc or desc, or a sql.Raw.

Returns Query

Query.limit()

Returns at most count rows.

Parameters

  • count (number)

Returns Query

Query.offset()

Skips the first count rows.

Parameters

  • count (number)

Returns Query

Query.scope()

Applies a scope the model declared.

Parameters

  • name (string)
  • argument (any) — Handed to the scope.

Returns Query

Raises ModelError if the model declares no such scope.

Query.include()

Loads associations along with the records.

Parameters

  • names (string|list[string]) — Association names, dotted to reach the associations of what they load.

Returns Query

Query.all()

Every matching record.

Returns list[Model]

Query.first()

The first matching record, or nil. Ordered by the primary key when no order was given, so it is the same one every time.

Returns Model|nil

Query.find()

The record with primary key key.

Parameters

  • key (any)

Returns Model

Raises RecordNotFound if there is none.

Query.find_by()

The first record meeting conditions, or nil.

Parameters

  • filter (dict)

Returns Model|nil

Query.exists()

Whether any row matches.

Returns bool

Query.count()

How many rows match. Order, limit and offset do not change it.

Returns number

Query.pluck()

One column of every matching row, cast as the model casts it.

Parameters

  • column (string)

Returns list

Query.sum()

The total of a column over the matching rows, as the engine reports it: a number, or a sql.Decimal for an exact column on PostgreSQL and MySQL. Nil when no row matches.

Parameters

  • column (string)

Returns number|Decimal|nil

Query.min()

The smallest value of a column over the matching rows, or nil.

Parameters

  • column (string)

Returns any

Query.max()

The largest value of a column over the matching rows, or nil.

Parameters

  • column (string)

Returns any

Query.average()

The mean of a column over the matching rows, as the engine reports it, or nil.

Parameters

  • column (string)

Returns number|Decimal|nil

Query.page()

One page of the matching records, and where it sits among them.

Parameters

  • number (number) — Which page, counting from 1.
  • size (number) — How many records to a page.

Returns dict — { records, total, page, size, pages }, total the matching records in all and pages how many pages they fill, at least 1.

Query.stream()

The matching records read one at a time, for more than fit in memory at once. Associations are not loaded this way.

Returns RecordCursor

Raises ModelError if the query includes associations.

Query.create()

Creates a record from attributes and saves it.

Parameters

  • attributes (dict) — Assigned as fill() assigns them.

Returns Model

Raises RecordInvalid if it fails validation.

Query.update()

Updates every matching row in one statement, without building the records: no validation runs and no hook is called. The model's updated timestamp is set too, unless values sets it.

Parameters

  • values (dict) — Column to value, a sql.Raw written as given.

Returns number — How many rows changed.

Query.delete()

Deletes every matching row in one statement, without building the records: no hook is called. With no conditions, that is every row.

Returns number — How many rows went.

Query.from_sql()

Records built from a statement of one's own, for what conditions cannot say: a join, a union, a window. The statement selects the model's columns by their names.

Parameters

  • sql (string)
  • params (list|dict|nil)

Returns list[Model]

Query.load()

Loads associations onto records already in hand, one query per association for all of them.

Parameters

  • records (list[Model]) — Records of this model.
  • names (string|list[string])

Returns list[Model] — The same records.

Query.to_sql()

The statement all() runs, and the values it binds.

Returns dict — { sql, values }
