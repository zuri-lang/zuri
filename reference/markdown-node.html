Text and Markup

markdown.node

markdown lifts part of this module out to its own top level; each name below is shown with the path that reaches it. Anything still spelled markdown.node.* needs import markdown.node.

The tree markdown.parse() builds.

Every node is a Node, told apart by its type. A node carries only the fields its type uses and leaves the rest nil, so a heading has a level, a link a destination and a title, and a paragraph neither.

Classes

Node

One node of a parsed Markdown document.

Treat children as read-only and change the tree through append_child() and the methods beside it, which keep every child's parent_node right.

  • printable — has a @to_string(), so echo and print() show something useful

Fields

Field Type Description
type string What the node is: 'paragraph', 'link', 'text' and so on.
parent_node ?Node The node this one belongs to, or nil for a document and for a node that has been detached.
children list The node's children, in document order.
literal ?string The text of a text, code, code_block, html_block, html_inline, math, math_block or emoji node.
level ?number A heading's level, from 1 to 6.
info ?string A fenced code block's info string, the text after the opening fence, with escapes and entities resolved.
destination ?string Where a link points or an image comes from, percent-encoded.
title ?string A link's or image's title, or an abbreviation's expansion.
ordered ?bool Whether a list is numbered.
start ?number The number an ordered list starts at.
delimiter ?string What follows an ordered list's numbers: '.' or ')'.
bullet ?string The character a bullet list's items start with: '-', '*' or '+'.
tight ?bool Whether a list or a definition is tight.
checked ?bool A task list item's state: true when checked, false when not.
align ?string A table cell's alignment: 'left', 'center', 'right', or nil for none.
label ?string A footnote's label, as written between [^ and ], or an emoji's shortcode without its colons.
kind ?string An alert's kind: 'note', 'tip', 'important', 'warning' or 'caution'.
display ?bool Whether a math node was written with $$ and is shown on its own line rather than in the text.
attributes dict HTML attributes for the node's element, from a {#id .class key=value} block or a generated heading id.
metadata ?dict The front matter a document opened with, decoded, or nil when it had none.
line ?number The source line a block starts on, counting from 1.
end_line ?number The source line a block ends on, counting from 1.

Node.walk()

Calls callback with every node beneath this one, in document order. Returning false from it skips that node's children.
