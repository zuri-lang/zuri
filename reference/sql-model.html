Databases

sql.model

sql does not re-export this module, so it is reached only by importing it directly.

Rows as objects: a class per table, records that save and check themselves, and the associations between them.

A model is a class extending Model. Its fields are its table's columns, read and written by name, and a static define() says the rest: the table, how values are cast and checked, and what the model is associated with.

Records and connections

db.model(Post) starts a Query on a connection or a transaction, and every record method that touches the database takes the one to use: post.save(db), post.delete(tx). A record never holds a connection of its own, so the same record saves inside whichever transaction the code saving it opened, and one kept after its connection went back to a pool cannot write through a connection that is now somebody else's.

What is loaded

Associations are loaded when asked for: by include() on a query, one query per association however many records there are, or by load() on a record. A field holding an association is nil until then. Each query builds its own records, so two queries reaching the same row build two records of it, which are == to each other.

Tables

A model maps a table that exists; sql.migrate and db.schema are what create and change it.
