The Zuri Standard Library

test.result

import test.result

test lifts part of this module out to its own top level; each name below is shown with the path that reaches it. Anything still spelled test.result.* needs import test.result.

The shapes a test run is made of: the tree the declarations build, and what running it produced.

Every reporter is handed these objects and nothing else, so a custom reporter has the same view of a run that the built-in ones do. See test.reporter for what a reporter does with them.

Constants

PENDING

test.result.PENDING = 'pending'

A test was declared and not yet run.

PASSED

test.result.PASSED = 'passed'

It ran and every assertion held.

FAILED

test.result.FAILED = 'failed'

It ran and something did not hold.

SKIPPED

test.result.SKIPPED = 'skipped'

It was not run: skip, a filter, or another test’s only.

TODO

test.result.TODO = 'todo'

It was declared with no body, as a note to write it later.

FLAKY

test.result.FLAKY = 'flaky'

It failed, was retried, and then passed.

Failure

class test.Failure

One thing that went wrong.

A test can carry more than one: a failing body and then a failing after_each are two separate answers to “what went wrong”, and collapsing them loses the one that explains the other.
