The Zuri Standard Library

validate.rules

import validate.rules

validate does not re-export this module, so it is reached only by importing it directly.

All built-in validation rule implementations. Rules are plain classes that extend Rule. They are not intended to be constructed directly; the Validator fluent builder and Schema handle construction and injection automatically.

Same

class validate.rules.Same < Rule

Passes when the field’s value matches the value of another field in the same data dictionary. Commonly used for password confirmation.

Requires needs_data() == true so that the Schema injects _data.

Example

  password:              validate.string().min_length(8),
  password_confirmation: validate.string().same('password'),

RequiredIf

class validate.rules.RequiredIf < Rule

Passes when this field is present and non-nil only if another field in the data satisfies a given condition. If the other field equals any of the given values, this field becomes required.

Example

  # "shipping_address" is required when "has_delivery" is true
  shipping_address: validate.string().required_if('has_delivery', true),
