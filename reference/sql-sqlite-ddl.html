Databases

sql.sqlite.ddl

sql does not re-export this module, so it is reached only by importing it directly.

Schema changes for SQLite.

Creating a table, adding an index and renaming a column are plain statements. Most other changes to a table that exists are not: SQLite's ALTER TABLE cannot change a column, add or drop a key, or drop a column that a key or an index uses. For those the table is built again, the way SQLite's own documentation lays out: a new table with the changed definition, the rows copied across, the old table dropped and the new one renamed into its place, then its indexes and triggers put back and the sequence behind an id() carried over, so no id is ever handed out twice.

The new definition is the old one with only the changed parts rewritten, read from the table's own create table text, so whatever else the table declared, checks and collations included, comes through as it was.

Foreign keys

Dropping a table that other tables refer to deletes from it first, and with foreign keys enforced that delete runs their on delete actions: building a table again would take every row referring to it along with it. So a rebuild only ever runs with enforcement switched off, which SQLite allows only outside a transaction. schema_change() does exactly that around every change it runs, sql.migrate runs each migration through it, and the foreign keys are checked before the change commits. A rebuild asked for inside a transaction while foreign keys are enforced raises NotSupportedError rather than risk the rows.

Constants

MAX_DECIMAL_PRECISION

The most significant digits a decimal() holds exactly here. SQLite keeps a decimal as a double, which carries fifteen.

SqliteDdl.schema_change()

Runs body with foreign key enforcement switched off, inside a transaction that takes the write lock at once when transactional is true, and checks every foreign key before it commits.

Enforcement is put back as it was however body ends. When it was off to begin with, nothing is switched and nothing is checked.

Parameters

  • connection (Connection) — Not already in a transaction.
  • body (function)
  • transactional (bool)

Returns any — What body returned.

Raises ForeignKeyViolation if the change left a row referring to one that is not there; the change is rolled back.

TableDefinition

A table's create table text, taken apart into its columns and constraints so a rebuild can rewrite just what changes.

Each item keeps the text it was written with. Only an item a change touches is replaced, which is what carries everything the blueprint knows nothing about through a rebuild unchanged.
