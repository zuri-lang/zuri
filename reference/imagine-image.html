Images

imagine.image

imagine lifts part of this module out to its own top level; each name below is shown with the path that reaches it. Anything still spelled imagine.image.* needs import imagine.image.

Image, a raster image stored as a buffer of RGBA pixels, and the methods that transform it.

Resizing, cropping, rotating, compositing, color adjustments and the named filters are all methods here. Operations that change the size of the image, such as resize(), crop(), rotate(), flip() and pad(), return a new image. Everything else changes the image it's called on and returns it, so that calls can be chained.

Classes

Image

A raster image, which is a rectangle of 8-bit RGBA pixels, with everything that draws on it, and everything that reshapes it, filters it or writes it out.

Which operations make a copy

There's one rule to learn here, because it's the only thing that isn't obvious:

  • Anything that changes the size of the image returns a new Image. resize(), crop(), rotate(), flip(), pad() and the others leave the original unchanged.
  • Everything else changes the image in place, and returns it. Drawing, filters and compositing all work on the image you call them on, and return it so that calls can be chained.

So a chain that mixes the two kinds still does what it looks like it does, and you can use clone() when you want to keep the original before applying a filter.

Memory

An image takes four bytes per pixel, so a 6000x4000 photograph takes 96 MB in memory, however small its file was. Use [[imagine.formats.probe]] before opening anything whose size you don't control.

  • printable — has a @to_string(), so echo and print() show something useful

Constructor

Creates a new image.

The image starts fully transparent, unless a fill color is given.

Parameters

  • width (number) — at least 1
  • height (number) — at least 1
  • fill (?Color|string|number) — a color to fill the image with. Defaults to transparent.

Raises BoundsError when either dimension is less than 1.

Image.open()

Opens an image file.

The format is detected from the file's contents, not its name, so a file with the wrong extension still opens correctly.

A JPEG with an EXIF orientation tag is rotated to be upright, because that's how the photograph was meant to look, and the raw pixels are almost never stored that way. Pass { orient: false } to get the pixels exactly as they're stored.

Parameters

  • source (string|file) — a path, or a file that's already open
  • options (?dict) — orient, a bool that defaults to true, and format, a string

Returns Image

Raises DecodeError when the file isn't an image that can be read.

Image.decode()

Decodes image data held in memory.

The format is detected from the data, unless format gives it. In that case, data that isn't really in that format fails with an error, instead of being decoded as whatever it actually is.

Parameters

  • data (bytes)
  • options (?dict) — orient, a bool that defaults to true, and format, a string

Returns Image

Raises DecodeError when the data isn't an image that can be read.

Image.from_pixels()

Wraps an existing buffer of RGBA pixels as an image.

The buffer is used as it is, not copied, so whatever produced it mustn't keep writing to it. Each pixel is red, green, blue and alpha, with straight alpha, not premultiplied, and there's no padding at the end of a row.

Parameters

  • width (number)
  • height (number)
  • pixels (bytes) — exactly width * height * 4 bytes
  • format (?string) — the format the pixels were decoded from, kept as metadata. Defaults to nil.

Returns Image

Image.size()

The image's dimensions as {width, height}.

Returns dict

Image.format()

The format this image was decoded from, or nil if it was created in memory.

This records where the image came from, and never limits where it can go. A PNG can always be saved as a JPEG.

Returns ?string

Image.set_format()

Sets the format that this image is treated as having come from.

The only thing this changes is the format that encode() and save() write when no format is given. It's set for you when an image is decoded. Set it yourself only for pixels that came from somewhere else, when you know their original format.

Parameters

  • format (?string) — a format name, or nil to clear it

Returns — self

Image.bounds()

The rectangle covering the whole image, as {x, y, width, height}.

Returns dict

Image.is_opaque()

true when every pixel is fully opaque.

This walks the alpha channel, so it costs a pass over the image. Worth knowing before choosing an output format: an opaque image loses nothing as a JPEG.

Returns bool

Image.info()

A summary of the image as a dictionary holding width, height, format, pixels (the count, not the buffer) and opaque.

Returns dict

Image.clone()

An independent copy of the image, sharing nothing with it.

Image.layer()

A new, fully transparent image of the same size.

This is the usual way to build up a composite: draw on the new layer, and then combine it with the original using draw_image(), with whatever blend mode and opacity the effect needs.

Parameters

Image.resize()

Returns the image resampled to an exact size.

The aspect ratio isn't kept, and the result is exactly the size you ask for. Use thumbnail() or cover() when the proportions matter.

Parameters

  • width (number) — at least 1
  • height (number) — at least 1
  • filter (?string) — a resampling filter. Defaults to LANCZOS.

Returns Image

Raises BoundsError when either dimension is less than 1.

Image.scale()

Returns the image resampled by a factor, keeping its proportions.

Parameters

  • factor (number) — greater than zero. 0.5 halves the length of each side.
  • filter (?string) — a resampling filter. Defaults to LANCZOS.

Returns Image

Image.thumbnail()

Returns the image shrunk to fit inside a box, keeping its proportions.

The result is no larger than the box in either direction, and it's usually smaller in one of them. An image that already fits is returned at its original size, because enlarging a small image to fill a thumbnail box only makes it blurry.

Parameters

  • max_width (number)
  • max_height (number)
  • filter (?string) — a resampling filter. Defaults to LANCZOS.

Returns Image

Image.fit()

Returns the image scaled to fit inside a box, keeping its proportions, and enlarging it if it's smaller than the box.

That's the only difference from thumbnail(): this method scales up as well as down.

Parameters

  • width (number)
  • height (number)
  • filter (?string) — a resampling filter. Defaults to LANCZOS.

Returns Image

Image.cover()

Returns the image filling a box exactly, keeping its proportions by cropping whatever overflows.

This is what a CSS background-size: cover does, and what almost every avatar or card thumbnail wants: the box is filled edge to edge with no distortion and no letterboxing, at the cost of losing some of the image.

Parameters

  • width (number)
  • height (number)
  • options (?dict) — anchor (where the kept part comes from, default CENTER), filter.

Returns Image

Image.contain()

Returns the image fitted inside a box exactly, keeping its proportions by padding whatever is left over.

The counterpart to cover(): nothing is lost, but the result has bars on two sides.

Parameters

  • width (number)
  • height (number)
  • options (?dict) — background (the padding color, default transparent), anchor (default CENTER), filter.

Returns Image

Image.crop()

Returns a rectangular part of the image.

The rectangle must be entirely inside the image. Clamping a crop that runs off the edge would return an image of a different size from the one you asked for, which is a worse surprise than an error. If the area really should extend past the edge, use pad() first.

Parameters

  • x (number)
  • y (number)
  • width (number)
  • height (number)

Returns Image

Raises BoundsError when the rectangle doesn't fit inside the image.

Image.trim()

Returns the image with a border of one color trimmed off.

The border color is taken from the top-left pixel, unless background gives one. tolerance is how much a pixel can differ from it and still count as border, measured as the largest difference in any of the four channels.

An image that's entirely border is returned as a 1x1 image, not an empty one, because this module can't represent an image with no pixels.

Parameters

  • options (?dict) — background, and tolerance, which defaults to 0

Returns Image

Image.pad()

Returns the image with a border added on each side.

Negative amounts aren't accepted. Use crop() to remove edges.

Parameters

  • top (number)
  • right (?number) — defaults to the same as top.
  • bottom (?number) — defaults to the same as top.
  • left (?number) — defaults to the same as right.
  • background (?Color|string|number) — defaults to transparent.

Returns Image

Image.rotate()

Returns the image rotated clockwise by an angle in degrees.

Quarter turns are exact and lossless. Any other angle resamples the pixels and enlarges the canvas to hold the rotated corners, filling the gaps with background.

Parameters

  • degrees (number)
  • background (?Color|string|number) — the color behind the corners. Defaults to transparent.

Returns Image

Image.rotate_90()

Returns the image turned a quarter turn clockwise. Lossless.

Image.rotate_180()

Returns the image turned upside down. Lossless.

Image.rotate_270()

Returns the image turned a quarter turn anticlockwise. Lossless.

Image.flip()

Returns a mirrored copy of the image.

Parameters

Image.flip_horizontal()

Image.transpose()

Returns the image reflected across its main diagonal, so a w x h image becomes h x w.

Image.apply_lut()

Rewrites every pixel through up to four 256-entry lookup tables, one per channel.

This is the primitive behind most of the adjustments below, and it is the fastest way to apply any per-channel tone curve: the table is built once whatever the image's size, and applying it is a single indexed load per channel.

A nil table leaves that channel alone. Tables are built with the helpers in [[imagine.filters]], or with [[imagine.filters.build_lut]] for a curve of your own.

Parameters

  • red (?bytes) — A 256-entry table, or nil.
  • green (?bytes)
  • blue (?bytes)
  • alpha (?bytes)

Returns — self

Image.apply_matrix()

Rewrites every pixel through a 4x5 color matrix.

The matrix is a flat list of 20 numbers, laid out row by row, and is the same shape SVG and CSS filters use. The last entry of each row is a constant added afterwards, in 0-255 units.

Applying several matrices in a row is both slower and less accurate than combining them with [[imagine.filters.combine_matrices]] and applying the result once.

Parameters

  • matrix (list) — 20 numbers.

Returns — self

Image.brightness()

Adds a fixed amount to every color channel.

Parameters

  • delta (number) — -255 to 255. Positive brightens.

Returns — self

Image.contrast()

Pushes colors away from or toward mid-gray.

Parameters

  • amount (number) — -100 (flat gray) through 0 (unchanged) to 100 (hard black and white).

Returns — self

Image.gamma()

Applies a gamma curve, moving the midtones without touching black or white.

Parameters

  • gamma (number) — Greater than zero. Below 1 darkens, above 1 lightens.

Returns — self

Image.levels()

Stretches a range of input values across the full scale.

This is the most useful single correction for a flat or washed-out photograph. Everything at or below black becomes black, everything at or above white becomes white, and everything else is spread out in between.

Parameters

  • black (number) — the input value that becomes black, from 0 to 255
  • white (number) — the input value that becomes white, from 0 to 255
  • gamma (?number) — a midtone curve to apply as well. Defaults to 1.

Returns — self

Image.invert()

Inverts the color channels, producing a photographic negative.

Alpha isn't changed, so a transparent image stays transparent, instead of becoming opaque.

Returns — self

Image.threshold()

Makes every pixel black or white, by comparing its brightness with a threshold.

The image is converted to gray first, so the decision is based on perceived brightness, not on each channel separately.

Parameters

  • level (?number) — the cutoff, from 0 to 255. Defaults to 128.

Returns — self

Image.posterize()

Reduces each channel to a fixed number of evenly spaced steps.

This turns gradients into visible bands. For a reduction that chooses which colors to keep, instead of spacing them evenly, use quantize().

Parameters

  • levels (number) — 2 or more

Returns — self

Image.opacity()

Scales the alpha channel, making the whole image more transparent.

The scaling is relative: applying 0.5 twice leaves a quarter of the original opacity, not half.

Parameters

  • factor (number) — 0 (invisible) to 1 (unchanged).

Returns — self

Image.grayscale()

Converts the image to shades of gray.

The channels are weighted for perceived brightness, so a bright yellow comes out light and a deep blue comes out dark, as the eye expects.

Returns — self

Image.sepia()

Gives the image the warm brown cast of an old photograph.

Returns — self

Image.saturate()

Scales the image's saturation.

Parameters

Image.hue_rotate()

Parameters

Image.duotone()

Maps the image's brightness onto a two-color ramp.

Dark pixels take shadow, light ones take highlight, and everything between is interpolated.

Parameters

  • shadow (Color|string|number)
  • highlight (Color|string|number)

Returns — self

Image.tint()

Blends a flat color into the image.

At an amount of 1, the image becomes that color entirely, and at 0.2, it takes on a slight tint of it. Alpha isn't changed, so transparent areas stay transparent.

Parameters

  • color (Color|string|number)
  • amount (?number) — from 0 to 1. Defaults to 0.5.

Returns — self

Image.colorize()

Converts to gray and then tints, producing a monochrome image in a single color.

Parameters

  • color (Color|string|number)

Returns — self

Image.quantize()

Reduces the image to at most a given number of colors.

Unlike posterize(), this chooses colors that suit the image, instead of spacing them evenly, so a photograph can be reduced to far fewer colors. Dithering replaces visible banding with a fine speckle, which almost always looks better when there are only a few colors.

This also shows what GIF export will do, because a GIF can't have more than 256 colors in a frame.

Parameters

  • colors (?number) — from 2 to 256. Defaults to 256.
  • dither (?bool) — defaults to false.

Returns — self

Image.premultiply()

Multiplies the color channels by alpha.

imagine keeps straight alpha everywhere, so this is for handing pixels to something that expects them premultiplied. It loses precision in near-transparent pixels and cannot be perfectly undone.

Returns — self

Image.unpremultiply()

Undoes premultiply(), as far as 8 bits allow.

Returns — self

Image.convolve()

Applies a convolution kernel to the image.

The kernel is a flat list of size * size numbers, where size is odd. The default divisor of 0 means "divide by the sum of the kernel", as almost every published kernel expects. Pass an explicit divisor for kernels whose weights add up to zero.

Alpha goes through the kernel along with the color channels, unless keep_alpha is set, so blurring a shape softens its edge, instead of leaving a hard cutout. Set keep_alpha for any kernel whose weights don't add up to one. A Laplacian kernel over an image that's opaque everywhere gives an alpha of zero, which would make the whole result invisible.

Parameters

  • kernel (list)
  • options (?dict) — divisor, which defaults to 0, offset, which defaults to 0, edge, which defaults to EDGE_CLAMP, and keep_alpha, which defaults to false

Returns — self

Image.blur()

Blurs the image with a true Gaussian blur.

The radius is the standard deviation of the blur in pixels. About two thirds of each pixel's contribution falls within that distance, and the visible spread is about three times as far. The cost increases with the radius, but only linearly, because the blur is separable.

Alpha is premultiplied while the blur runs, so blurring a shape on a transparent background doesn't create a dark halo around its edge.

Parameters

  • radius (?number) — greater than zero. Defaults to 2.

Returns — self

Image.sharpen()

Sharpens the image.

Parameters

  • strength (?number) — 1 is a moderate amount, and values much above 3 start to produce halos. Defaults to 1.

Returns — self

Image.smooth()

Softens the image with a weighted average of each 3x3 area.

It's cheaper and harsher than blur(), and always reaches exactly one pixel away.

Parameters

  • weight (?number) — how much of the original to keep. Defaults to 8.

Returns — self

Image.emboss()

Turns the image into a gray relief, as if stamped into metal.

Returns — self

Image.edges()

Leaves only the image's edges, everything flat going black.

Returns — self

Image.mean_removal()

Exaggerates local detail by removing the local mean.

Returns — self

Image.pixelate()

Replaces each block of pixels with its average color, producing the familiar mosaic used to hide parts of an image.

Parameters

  • size (?number) — the length of a block's side in pixels. Defaults to 8.

Returns — self

Image.draw_image()

Draws another image onto this one.

The source is clipped at this image's edges, and its position can be negative, so a sprite that hangs off the top-left corner is drawn correctly.

Parameters

  • source (Image)
  • x (?number) — defaults to 0.
  • y (?number) — defaults to 0.
  • options (?dict) — opacity, from 0 to 1, which defaults to 1, and blend, which defaults to BLEND_NORMAL

Returns — self

Image.place()

Draws another image onto this one, positioned by an anchor instead of by coordinates.

Parameters

  • source (Image)
  • anchor (?string) — defaults to CENTER.
  • options (?dict) — margin, the distance from the edges, which defaults to 0, and any of the options that draw_image() takes

Returns — self

Image.mask()

Uses another image as an alpha mask.

Each of this image's pixels keeps its color and takes its transparency from the mask: where the mask is opaque white this image shows through fully, where the mask is black or transparent this image disappears, and grays give partial transparency.

The mask's own alpha counts too, so a shape drawn on a transparent background works as a mask without being filled in first.

The mask must be the same size as this image.

Parameters

  • mask (Image)

Returns — self

Raises BoundsError When the mask is a different size.

Image.flatten()

Composites the image over a solid color, making it fully opaque.

This is what happens when an image is exported to a format without an alpha channel. Doing it yourself first lets you choose the color and see the result.

Parameters

  • background (?Color|string|number) — defaults to white.

Returns — self

Image.histogram()

Counts how many pixels hold each value, per channel.

Returns a dictionary of four 256-entry lists: red, green, blue and luma, where luma is perceived brightness. Fully transparent pixels are skipped, since their color is not visible and would otherwise pile up at whatever the buffer happens to hold there.

A histogram is what tells you an image is underexposed (everything bunched at the low end), flat (bunched in the middle), or clipped (a spike at 0 or 255).

Returns dict

Image.auto_levels()

Stretches the image's tones to fill the full range.

The black and white points are found from the brightness histogram, ignoring a small fraction at each end, so that a few stray pixels can't decide the result. This is the automatic version of levels(), and it's the first thing to try on a flat or hazy photograph.

An image that already covers the full range, or that has no visible pixels at all, is left unchanged.

Parameters

  • options (?dict) — clip, the fraction to ignore at each end, from 0 to 0.2, which defaults to 0.005, and gamma, a midtone curve to apply as well, which defaults to 1

Image.average_color()

The average color of the image.

Pixels are weighted by their alpha, so a mostly transparent image reports the color of the part you can actually see, instead of having it washed out by the transparent pixels. The alpha of the returned color is the average alpha.

An image with nothing visible in it returns transparent black.

Returns Color

Image.dominant_colors()

The colors that cover the largest part of the image, most common first.

The image is shrunk and reduced to a small palette first, so this takes about the same time whatever the original size is. Nearly transparent pixels are ignored.

The usual use for this is choosing a background or accent color to show while a photograph is still loading.

Parameters

  • count (?number) — the number of colors to return. Defaults to 5.
  • options (?dict) — sample, the size the image is reduced to before counting, which defaults to 96, and palette, the number of colors to quantize to, which defaults to 32

Returns list

Image.difference()

How different two images are, from 0 (identical) to 1.

The score is the mean difference across the color channels, weighted by how opaque each pixel is in either image, so transparent regions do not count as agreement. Images of different sizes are never comparable and return 1.

Image.encode()

Encodes the image and returns the bytes.

The options each format understands:

  • quality, from 1 to 100, for JPEG and AVIF. It defaults to 85 for JPEG and 80 for AVIF. It doesn't apply to WebP, which is written losslessly.
  • compression, for PNG: 'fast', 'default' or 'best'. All three are lossless, and they trade encoding time for file size.
  • speed, for AVIF, from 1 to 10, where lower is slower and gives smaller files, and for GIF, from 1 to 30, where lower is slower and chooses better colors. It defaults to 15 for GIF.
  • background, for JPEG, the color that transparent pixels are flattened against. It defaults to white.
  • threshold, from 0 to 255, for WBMP, the brightness cutoff.

Parameters

  • format (?string) — defaults to the format this image was decoded from, or PNG.
  • options (?dict)

Returns bytes

Raises EncodeError when the format can't be written.
