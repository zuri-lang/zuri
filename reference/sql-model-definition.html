sql.model.definition

sql lifts part of this module out to its own top level; each name below is shown with the path that reaches it. Anything still spelled sql.model.definition.* needs import sql.model.definition.

What a model is: its table, its columns, how its values are cast and checked, what it is associated with, and which of its hooks it has.

A model's class says most of it. Every field it declares that does not start with _ is a column of the same name, read and written as the field. The rest it says in a static define(), which is handed a Definition to describe itself on:

define() runs once, the first time the model is used, not when its class is declared, so it can name a model declared after it in the same file. What it describes is checked against the class then, and a definition that cannot work, an association with no field to hold it, a cast on a field that is not a column, raises ModelError at that first use rather than somewhere further on.

Constants

BELONGS_TO

A record holding the key of another, which it belongs to.

HAS_ONE

A record that another holds the key of, one of at most.

HAS_MANY

A record that others hold the key of, any number of them.

BELONGS_TO_MANY

Records joined to others through a table holding both keys.

HOOKS

The methods a model overrides to run code around its own life. Each is called with the connection or transaction the record is being saved or deleted through, except after_load(), called as a record is built from a row.

Functions

definition_of()

The definition of model, made the first time it is asked for and kept from then on.

Making it builds one record of the class, with no arguments, to be sure it is a model, then runs its define() when it has one.

Parameters

  • model (class)

Returns Definition

Raises ModelError if model is not a class extending Model, or its definition cannot work.

Definition

A model's description: what define() is handed to write it on, and what everything else reads once it is finished.

The methods a model calls in define() each return the definition, so they can be chained, and each is checked against the class when the definition is finished.

  • printable — has a @to_string(), so echo and print() show something useful

Fields

Field Type Description
model class The model's class.
name string The model's class name.
table_name string The table.
primary The primary key's column.
columns list[string] The columns, in the order the class declares their fields.
created_column The column stamped when a record is created, or nil.
updated_column The column stamped whenever a record is saved with a change, or nil.
casts dict The cast of each column that has one.
validators dict The validate.Validator of each column that has one.
uniques list[dict] The checks for values no other row may share, each { columns, message }.

hidden_columns list[string] The columns left out of to_dict() and @to_json().
transient_fields list[string] The fields that are not columns.
scopes dict The scopes, by name.
associations dict The associations, by name.
hooks dict Which hooks the model overrides, by name.
schema The validators as one validate.Schema, or nil when there are none.
transactional Whether saving and deleting run in a transaction of their own: when the model has hooks or unique checks,...

Definition.unique()

Checks before a record is saved that no other row holds the same values in columns. A record with nil in any of them is not checked, as a unique index lets any number of nulls through.

This reports a taken value as a validation failure, with the rest. Only a unique index in the database makes two records saved at the same moment unable to take the same value; keep one there too.

Parameters

  • columns (string|list[string])
  • message (string|nil) — What a person reads, The <column> field has already been taken. when nil.

Returns Definition
