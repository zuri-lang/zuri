The Zuri Standard Library

net

import net

The net module provides networking primitives for Transmission Control Protocol and User Datagram Protocol communication as well as IP address manipulation interfaces.

  • TcpStream communicates over TCP.
  • UdpSocket communicates over UDP.
  • UnixStream communicates over a unix domain socket, which is a path on the filesystem rather than an address on the network.
  • Ip parses, formats and classifies IP addresses.
  • SocketAddr pairs an IP address with a port.
  • net.tls wraps a TcpStream in Transport Layer Security.
  • net.dtls provides Datagram Transport Layer Security over UDP.
  • net.poll waits on many sockets at once.
  • net.resolver asks the domain name system questions of its own.
