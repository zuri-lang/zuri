Text and Markup

markdown.renderer

markdown lifts part of this module out to its own top level; each name below is shown with the path that reaches it. Anything still spelled markdown.renderer.* needs import markdown.renderer.

Turning a parsed document into HTML.

HtmlRenderer writes the markup the CommonMark reference implementation writes, byte for byte, so its output can be compared with any other conforming renderer's. Each node type has a method of its own name, and a subclass changes how one kind of node looks by overriding that method alone:

Inside a method, write() adds markup as it is, text() adds text escaped, cr() starts a new line unless one was just started, and render_children() renders what the node holds.

Classes

HtmlRenderer

Renders a parsed document as HTML.

One renderer renders one document at a time. markdown() makes a fresh one for every call to render(), so a subclass may keep whatever state it likes in fields of its own.

  • printable — has a @to_string(), so echo and print() show something useful
