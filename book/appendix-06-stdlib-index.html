Appendix F: The Standard Library Index

Every module in the standard library, what it is for, and where the book covers it. All of them are reachable with a bare import, with no package manager and no dependency to add.

Each module's source is in libs/, and every public function in it carries a doc block stating its parameters, its defaults and its edge cases.

Packages and Their Submodules

Most of the larger modules are packages: a directory whose index.zu re-exports what its parts make public. import http reaches almost all of http without naming a submodule. Import a submodule directly when you want only that part of it, or when a name would otherwise collide.

Shadowing a Module

A file in ./.zuri/libs/ shadows a standard library module of the same name, because that directory is searched first. See The Module System.
