Programming a Bookmark Keeper

In this chapter we'll build a small but useful program: a command-line bookmark keeper. It asks for a title and a URL, saves them to a JSON file, and lets you list, search and delete bookmarks later.

Along the way, you'll use variables, functions, lists, dictionaries, loops, branches, string methods, files, JSON and error handling. We won't explain any of them in depth here, because that's what Chapters 3 to 8 are for. The goal of this chapter is to show you a complete, working program before we look at each part in detail.

Try typing the code in yourself instead of copying it. Making mistakes is the quickest way to learn what the error messages mean.

Saving to Disk

The json module converts Zuri values to text and back. file() opens a file, and 'w' opens it for writing.

def declares a function. The parameters don't need types, although you can add them (see Chapter 5). The body is a block, and in Zuri, blocks always use braces.

The second argument to json.encode() is called compact. It defaults to true, which puts everything on one dense line. Passing false gives you indented output instead, which is easier to read if someone opens the file:

Loading the File Safely

Reading the file is where a real program has to think about what might go wrong. The file might not exist yet. Or it might exist but contain invalid JSON because someone edited it by hand. Neither case should crash the program.

This code introduces two new things.

The first is ${...} inside a string. This is called interpolation: the expression inside the braces is evaluated, and its value is inserted into the string. Interpolation works in both single-quoted and double-quoted strings.

The second is catch. Zuri doesn't have try. Instead, you wrap the code that might fail in catch { ... } and handle the error in as error { ... }. If nothing goes wrong, the handler doesn't run. If something does, error is an object with message, type and stacktrace properties.

There's no finally either. Code after the catch statement runs whether or not there was an error, which covers most of the things finally is normally used for.

The line that builds the tags uses three new ideas.

cond ? a : b is the conditional operator. If cond is truthy, the result is a. Otherwise, it's b.

split(',') splits a string into a list at each comma.

map() calls a function on every element of a list and returns a new list of the results. @(t) { return t.trim() } is an anonymous function, written as @ followed by a parameter list and a body. You can also write it as def(t) { ... }, but @ is the shorthand, and it's what most Zuri code uses for short functions.

Listing and Searching

each() calls your function once for every element, passing the value first and the index second. This order surprises some people. It's the same for lists, dictionaries and strings.

filter() keeps the elements for which your function returns true. some() checks whether a condition is true for at least one element, and it stops as soon as it finds one.

Removing a Bookmark

to_number() converts a string to a number, bookmarks[position] gets an element of a list by its index, and remove_at() removes the element at a given position and moves the remaining elements down.

The bounds check is necessary. Reading past the end of a list raises an error, and an error that isn't handled ends the program.

The Main Loop

The last piece is a loop that reads a command and decides what to do with it:

using is Zuri's multi-way branch statement, and each branch starts with when. It compares the value against each when and runs the first branch that matches. The default branch handles everything else. When a branch's body is a single short statement, it can stay on the same line, which keeps a dispatch table like this one easy to read. Longer bodies need a block.

Unlike switch in C, there's no fall-through, so you don't need break. One branch runs, and then the statement is finished.

Summary

You've just written a program with persistent state, user input, error handling and a command loop, in about a hundred lines, using only what comes with Zuri.

Along the way, you've seen var, def, if/else, while, using/when, catch/as, return, lists, dictionaries, the dictionary shorthand, string interpolation, the conditional operator, anonymous functions and a number of built-in methods.
